# MyFirst-Todo-App
# 📝 Modern Todo App

## Description
A clean, responsive, and fully functional Todo App built entirely from scratch using vanilla web technologies. This app helps you track your daily tasks with a sleek dark-themed UI. It includes built-in browser storage, meaning you will never lose your tasks even if you refresh or close the page!

## Features
* **Add Tasks:** Type a task and click "Add Task" or simply press the `Enter` key.
* **Duplicate Prevention:** Automatically blocks you from adding the exact same task twice.
* **Mark as Done:** Click on any task text to cross it out and mark it as completed.
* **Delete Tasks:** Remove individual tasks using the "Delete" button.
* **Clear All:** Wipe the slate clean with a single click using the "Clear All" button.
* **Live Counter:** Keeps track of your overall progress (e.g., "Total: 5 | Done: 2").
* **Smart Filters:** Switch between viewing "All", "Done", or "Active" tasks to stay focused.
* **Persistent Storage:** Uses the browser's `localStorage` to save your data automatically.

## How to Run the App
1. Create a project folder on your computer.
2. Inside that folder, ensure you have three files: `index.html`, `style.css`, and `script.js`.
3. Paste the corresponding code into each file and save them.
4. Double-click the `index.html` file to open it in any web browser (Chrome, Firefox, Safari, etc.).
5. Start adding your tasks!

## Technologies Used
* **HTML5:** For the structure and layout of the app.
* **CSS3:** For the dark-mode styling, hover effects, and flexbox alignment.
* **Vanilla JavaScript:** For DOM manipulation, event handling, data filtering, and local storage integration.
